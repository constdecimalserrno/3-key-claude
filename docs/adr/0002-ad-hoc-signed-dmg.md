# The Helper ships as an ad-hoc signed, not notarized .dmg

Besides building from source, 3-key Claude is handed out as a `.dmg` on GitHub Releases ( `./install.sh dmg`, published with `./install.sh release <tag>` ), so nobody needs the terminal to get going. It's ad-hoc signed and NOT notarized: notarizing needs a Developer ID certificate from the paid Apple Developer Program, and this is a free hobby repo. The cost is that Gatekeeper blocks the first launch of a downloaded copy, so everyone does a one-time "Open Anyway" in System Settings > Privacy & Security, and the README, the `.dmg`'s read-me and the guide all say so. An ad-hoc signature also changes with every build, so macOS forgets the app's Accessibility and Automation grants on every update ( same as ADR-0001 ). The `.dmg` holds a universal app ( Apple silicon and Intel, two `swiftc` runs glued together with `lipo` ), source installs only build for their own chip. A paid account would fix the first two later without changing anything else.
