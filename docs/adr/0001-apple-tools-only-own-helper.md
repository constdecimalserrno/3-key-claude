# Only Apple's tools, so the Helper is our own Swift app

This repo is public and meant for anyone with a Mac, so it depends only on what Apple ships ( macOS, its built-in scripting, and the Swift compiler from Apple's Command Line Tools ), with Homebrew allowed only when there's truly no other way. That ruled out Hammerspoon ( crash uploads and update checks on by default, plus a Lua runtime and plugin system we don't need ), Karabiner, skhd, BetterTouchTool and Raycast, so the Helper is a small Swift app we write and each Mac builds from source. The cost is that we maintain it, and macOS forgets the Helper's Accessibility permission every time it's rebuilt. Prebuilt copies now ship too, as an ad-hoc signed, NOT notarized `.dmg`, see [ADR-0002](0002-ad-hoc-signed-dmg.md).
